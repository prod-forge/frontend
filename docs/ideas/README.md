# Ideas

Raw, high-level ideas that are not ready for work. An idea can be a few lines: the problem, the rough direction and any link that prompted it. When an idea is worked out and assigned to a version, it moves to [roadmap/](../roadmap/), and its tasks to a plan in [plans/](../plans/).

- [localization.md](localization.md) — a second language for both clients from one shared message catalog.

## Format

One file per idea, `<topic>.md`:

```markdown
# <Idea>

## Problem

<What is missing or painful.>

## Direction

<A rough approach, open questions.>
```
